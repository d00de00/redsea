# RedSea — منظومة الملاحة البحرية الذكية 🌊🧭

تطبيق PWA للملاحة البحرية يعمل على الهواتف الذكية بدون تثبيت من متجر، مبني بـ:
- **Leaflet 1.9.4** — محرك الخرائط
- **Esri ArcGIS Ocean / Imagery / Transportation** — طبقات الخرائط
- **Open-Meteo API** — الطقس والضغط الجوي
- **sql.js 1.8** — قراءة قواعد بيانات MBTiles / .sqlitedb
- **Tailwind CSS** (CDN) + **Font Awesome** + **Cairo** (Google Fonts)

---

## المتطلبات

| المتطلب | السبب |
|---------|-------|
| **HTTPS** | Service Worker + GPS + AudioContext + WakeLock تتطلب سياقًا آمنًا |
| متصفح حديث | Safari 15+ / Chrome 100+ |
| إذن GPS | لتتبع الموقع المباشر |
| إذن الحساسات | للبوصلة (على iOS فقط) |

> ⚠️ فتح الملف عبر `file://` لن يعمل — استخدم خادمًا محليًا:
> ```bash
> python3 -m http.server 8080
> # أو
> npx serve
> ```

---

## التثبيت كتطبيق

### iOS (Safari)
1. افتح الرابط عبر **Safari**.
2. اضغط زر **المشاركة**.
3. اختر **"إضافة إلى الشاشة الرئيسية"**.

### Android (Chrome)
1. افتح الرابط عبر **Chrome**.
2. اضغط قائمة **النقاط الثلاث**.
3. اختر **"تثبيت التطبيق"**.

## الميزات

- 🗺️ **3 خرائط أساسية**: أعماق (Ocean) / قمر صناعي / مشتركة.
- 📍 **معالم قابلة للتعديل**: صيد، مراسي، خطر، منارات، عوامات.
- 📏 **أداة قياس مسارات** وحفظها بأسماء.
- 🧭 **بوصلة** بالحساسات، مع إعادة توجيه للشمال.
- ⚓ **أوامر إبحار** مع مسافة واتجاه ووصول تقديري (ETA).
- 🚨 **تنبيه اقتراب** صوتي + اهتزاز على مسافة 100م من الوجهة.
- 📡 **تتبع حي** بـ GPS مع سهم يدور حسب الاتجاه.
- 🌦️ **طقس فوري** (حرارة + رياح) محدَّث كل 60 ثانية.
- 🎣 **تقويم صيد** 7 أيام: مد وجزر، شروق/غروب، أطوار القمر، ضغط جوي، تقييم.
- 🗂️ **استيراد خرائط**: GeoJSON, MP (Polish), MBTiles (.sqlitedb).
- 💾 **تصدير .mp** متوافق مع cGPSmapper / QLandkarte.
- 🌙 **العمل دون اتصال** بعد أول زيارة بفضل Service Worker.
- 📵 **بدون تسجيل دخول** — كل البيانات محفوظة في `localStorage` على جهازك فقط.
